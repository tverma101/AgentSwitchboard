# AgentSwitchboard issue and evidence map

This legacy-named page is a compatibility pointer, not an inventory of the
current GitHub backlog. Use the [documentation catalogue](README.md) to discover
maintained user guides, contracts, research notes, and evidence records.

For reusable deterministic/live validation commands, see
[certification](OPEN_ISSUE_CERTIFICATION.md) and the
[command reference](OPEN_ISSUE_SWEEP_COMMANDS.md). For the boundaries of the
recorded implementation sweep, see [sweep status](OPEN_ISSUE_SWEEP_STATUS.md).
For learning-related provenance, see [reviewer scars](REVIEWER_SCARS_UPSTREAMS.md).

Issue identifiers in these records preserve historical traceability and may be
associated with a shared certification step. They do not by themselves establish
that an issue remains open, that a receipt-only request is planned, or that a
boundary is broadly supported.
