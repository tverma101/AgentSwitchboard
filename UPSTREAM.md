# Upstream attribution

AgentSwitchboard is an independent open-source project that began from the
MIT-licensed Free Claude Code codebase. The upstream name is retained here for
provenance and for the compatibility identifiers that have not yet moved to the
public AgentSwitchboard namespace.

## Original project

- **Name:** Free Claude Code
- **Repository:** [Alishahryar1/free-claude-code](https://github.com/Alishahryar1/free-claude-code)
- **License:** MIT; the upstream notice is preserved in [LICENSE](LICENSE).

The earliest recoverable commit in this repository is
[`6c9f0c8a5a7da76efabf54316038db08e52e5690`](https://github.com/tverma101/AgentSwitchboard/commit/6c9f0c8a5a7da76efabf54316038db08e52e5690),
dated 2026-01-28 and titled `initial commit`. It is the earliest local
provenance point available here, not a claim that it is the upstream tip.

## Relationship to AgentSwitchboard

AgentSwitchboard has substantially diverged from the original project. It now
combines multiple client protocols, provider-independent routing and policy,
local browser/computer-use capability planes, profiles and account controls,
context governance, learning surfaces, and certification tooling. The current
product name is AgentSwitchboard; `fcc*`, `FCC_*`, and `free_claude_code` remain
explicit compatibility identifiers until a separately validated namespace
migration is completed.
